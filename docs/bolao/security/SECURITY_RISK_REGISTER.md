# Security Risk Register — Plataforma Bolão

2026-08-02. Versão resumida/priorizada da `SECURITY_RISK_MATRIX.md` (30 linhas RM-001..RM-030,
com escala formal). Este registro reagrupa os achados mais acionáveis em prioridade P0-P3, para
uso direto como lista de trabalho. Prioridades julgadas caso a caso, não atribuídas
automaticamente — a maioria dos achados desta auditoria é P1-P3, não P0, porque a maior parte do
comportamento observado é **consistente com decisões de produto já documentadas e aceitas**
(bolão informal, transparente, sem backend). Um item é destacado como o mais próximo de um P0
verdadeiro — ver linha SR-01.

**Prioridades**: P0 (alteração/exposição crítica já possível) / P1 (risco alto, exploração
viável) / P2 (relevante, sem urgência) / P3 (hardening/governança).
