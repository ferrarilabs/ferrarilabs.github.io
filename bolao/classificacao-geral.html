Como foi calculado
Pontuação, chaveamento e bônus de pódio replicados função por função a partir do código real do site (scoreEntry, matchPoints, podiumFromResults) contra o estado real salvo no banco (23 entradas, resultados oficiais confirmados até as semifinais — jogos 73 a 102).

Situação (Vivo/Eliminado) é uma checagem exaustiva — testamos todos os placares e lados de classificação fisicamente registráveis pelo admin nos 2 jogos que restam (3º lugar e Final) e vimos se existe algum resultado possível — mesmo que improvável — que coloque o participante em 1º, 2º ou 3º do bolão. "Fisicamente registráveis" importa: o placar decide sozinho quem avança sempre que não é empate (o formulário do admin trava isso automaticamente — só em empate no tempo normal + prorrogação o admin escolhe manualmente quem avançou nos pênaltis), e a checagem só considera resultados que respeitam essa regra. Se não existe nenhum resultado válido, está matematicamente eliminado do pódio.

A coluna de chance mistura dois tipos diferentes de resposta, e cada célula mostra o tipo certo — nunca os dois misturados como uma porcentagem só:

  • Garantido — prova matemática exaustiva: não existe nenhum resultado possível dos 2 jogos restantes que tire o participante dessa posição ou pior. Não é uma estimativa, é uma certeza.
  • Porcentagem — estimativa por simulação (1.500 rodadas de Monte Carlo, usando a força de cada seleção do site para gerar placares plausíveis). Por definição, nunca aparece como "100%" — se fosse 100% garantido, a célula mostraria "Garantido" em vez de um número.
  • <0,1% — o participante está matematicamente vivo para essa posição (existe um resultado possível que chega lá), mas o caminho é raro o bastante que as 1.500 simulações realistas não bateram nele nenhuma vez. Vivo não é o mesmo que provável.
  • — — matematicamente impossível: nenhum resultado dos jogos restantes chega nessa posição.
