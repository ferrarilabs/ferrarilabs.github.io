Como funcionam os simuladores?

⚡ Simulador automático

Tenta usar probabilidades por jogo do Polymarket quando encontra um mercado compatível para aquela partida. Se não encontrar, usa um modelo local simples de força estimada dos times. Ele sorteia o vencedor respeitando a probabilidade, então duas simulações podem sair diferentes.

🎲 Simulador maluco

Preenche palpites de forma quase aleatória, para quem quer brincar ou não quer pensar muito. Não usa estatística séria e pode gerar resultados improváveis.

Aviso: simulação é entretenimento, não recomendação de aposta. Probabilidades podem estar incompletas, desatualizadas, mal mapeadas ou indisponíveis.

Diagnóstico técnico: para ajudar em suporte e auditoria, esta versão registra metadados como IP público, dispositivo, navegador, timezone e horário de envio junto com a entrada.

A simulação é só para preencher rápido. Revise antes de salvar.

Como preencher os jogos futuros

Exemplo: se no Match 73 você colocou Brasil para passar, uma fase futura pode aparecer como “Vencedor Match 73”. Se na vida real outro time passar no lugar, esse time herda a vaga. Seu palpite futuro continua valendo para aquela posição do bracket.
