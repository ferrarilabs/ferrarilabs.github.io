Bolão documentation lives in two places:

1. `CLAUDE.md` at repo root — the single source of truth for agents; read it first in every session.
2. `docs/bolao/` — extended documentation (architecture, security, QA, governance, per-feature docs).

`CHATGPT.md` is only a pointer to `CLAUDE.md`.

**Why:** Eduardo asked for this to cut repeated context-setting across sessions.

**How to apply:** For any Bolão task, read `CLAUDE.md` first. For deep dives, read the relevant `docs/bolao/` file rather than reading source code cold.
